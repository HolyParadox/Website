# 🌐 SAP Horizon – Bilingual WordPress Portfolio Website

A custom-built bilingual (German & English) WordPress portfolio website designed for presenting SAP development services and showcasing professional projects. Built manually with attention to both technical clarity and visual storytelling, the website provides an engaging experience for potential clients.

## 🌟 Features

- 🔄 **Bilingual Support** – All content translated manually (not machine-generated) for native-level clarity in both German and English.
- 💼 **Clean Corporate Design** – SAP-themed visual language with intuitive navigation and clear calls-to-action.
- 🖼️ **Project Portfolio Integration** – Each project includes:
  - Short technical summary
  - GitHub link
  - Screenshots and descriptions
- 📱 **Responsive Design** – Optimized for desktop, tablet, and mobile viewing.
- ⚙️ **Custom Theme Edits** – Manual CSS and theme customization (no page builder dependency).
 
> All screenshots are available in the `/screenshots/` folder.

## 📁 Technologies Used

- **WordPress CMS**
- **Custom CSS Styling**
- **Manual Translation (EN/DE)**
- **Screenshot Optimization for Performance**
- **Hosted on Live Server (Deployment-ready)**
